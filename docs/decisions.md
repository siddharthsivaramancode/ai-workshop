## 2026-11-10: Initial scoping

| Question | Decision |
|---|---|
| Audience | Middle and high schoolers (about ages 11–18). We may narrow this later; see open questions. |
| Location | Collierville library first. Memphis Public Libraries later. |
| Who runs it | Two high-school students, peer-led. No budget yet. |
| Format | A series of weekly sessions over several weeks, ending in a demo day |
| What "vertical building" means | Each teen takes one small project all the way from an idea to a working, shared product (a website or app), using AI tools like Claude |
| What success means for the first run | 1. Every teen ships something real that they can show people. 2. Teens understand AI critically: how it works, where it fails, bias, privacy, and when not to trust it. |

Not goals for the first run: growing into a nonprofit, or resume value. These can come later.
