**Version 1** is git tag `v1`. To get those exact files back: `git checkout v1 -- slideshows/`.

## How v1 was made

- Each deck is generated by `curriculum/decks/build_session_0N.py`.
- The shared colors, layouts and animations are in `curriculum/decks/deckkit.py`.
- The speaker notes on each slide hold the presenter script.
- The minute-by-minute plan for each session is in `curriculum/session-0N-*.md`. Slide numbers in those plans match the decks.

If you redesign the decks by editing the `.pptx` files directly, the build scripts will no longer match them, and running a script again would overwrite your edits. Either keep editing the `.pptx` files and stop using the scripts, or update the scripts too.

Check a deck: `uv run --with python-pptx python curriculum/decks/check_deck.py slideshows/*.pptx`
